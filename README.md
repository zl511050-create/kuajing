# FastMoss 墨西哥 TikTok 本土选品与智能体研判中枢 · 私有化版

面向墨西哥 TikTok 本土店的高能选品大盘、AI 研判工作台与全成本利润模型中枢。支持 Windows 与 macOS 双系统开箱即用。

---

## 🚀 快速启动指南

### 方式一：Windows 用户（极简双击启动）
1. 确保电脑已安装 **Python 3.9+**（安装时务必勾选 `Add python.exe to PATH`）。
2. （可选）安装 Playwright 与图像依赖（如需开启自动化爬虫）：
   打开终端/CMD 执行：
   ```cmd
   pip install -r requirements.txt
   playwright install chromium
   ```
3. **直接双击运行 `start.bat`**。
4. 在浏览器中打开：**`http://127.0.0.1:8688`**。

### 方式二：macOS 用户
1. 打开终端（Terminal）进入项目目录：
   ```bash
   chmod +x start.sh
   ./start.sh
   ```
2. 在浏览器中打开：**`http://127.0.0.1:8688`**。

## ⚠️ 迁移注意事项与目录清理规范

在将本项目压缩打包发送前，请务必执行以下排除规则：
* **严禁打包**：`scraper/browser_profile/` 与 `scraper/browser_profile_flagship/`（占用 ~900MB，为当前电脑的本地临时缓存与锁定文件，迁移会引发冲突）。
* **保留核心数据**：保留 `database/fastmoss_hub.db`（历史商品与评分数据）及 `static/thumbs/`（缩略图），对方开箱即可看到完整数据大盘。
